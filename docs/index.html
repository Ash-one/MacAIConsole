就是你的 AI Runtime。

MacAI 把 LLM、语音识别和语音合成装进一个 daemon：aiworkd 管着模型注册、推理 worker 和内存调度。推理全部跑在本机的 Metal 与 MLX 上—— 没有云端，没有遥测，数据不出这台 Mac，拔了网线照常干活。

隐私优先 · Local-first

所有处理都发生在你的 Mac 上

没有云端推理，也没有遥测上报。模型、任务数据和日志都收在这台机器里；只有用户显式触发的模型、Runner 环境或引擎下载会访问配置的下载源。

推理全在本地

LLM、语音识别、语音合成，全由本机的 Metal、MLX 和 CPU 执行。推理请求没有云端转发路径。

断网照常工作

模型权重和任务数据都在本机磁盘上。除了第一次下载模型，日常使用用不到网络。

最小网络暴露

aiworkd 只绑 127.0.0.1，也没有做认证——所以它只服务本机。没有内置遥测，不向任何服务外发统计。

最小化落盘

日志里没有 API token，也没有模型内容；原始音频不进任务历史。

为什么是 MacAI

一个 daemon，管住所有推理

GUI、CLI、SDK，都只是客户端。模型状态、内存、生命周期，只属于 aiworkd——没有第二套运行时，也不该有。

单一 Runtime Authority

macai、MacAIConsole、OpenAI SDK，全都走同一个 HTTP API。UI 上显示的每个状态值都来自 daemon 本体——客户端自己不知道，也不需要知道模型的事。

进程级故障隔离

llama.cpp、whisper.cpp、Python worker，各自是独立进程。某个引擎崩了——段错误、OOM 都算——daemon 活得好好的，客户端收到的是 backend_crashed 这样的结构化错误，其他模型照常服务。

内存调度与租约保护

预算按 min(RAM×0.75, RAM−8GB) 划，LRU 逐出、keep-alive、空闲自动卸载都可配置。请求期间挂着 model lease——卸载永远打断不了正在跑的推理。

OpenAI 兼容 API

/v1/chat/completions（逐 token SSE）、/v1/audio/transcriptions、/v1/audio/speech。现有的 OpenAI SDK 代码改个 base_url 就能接上。

原生 SwiftUI 控制台

运行状态、内存压力、模型仓库、任务历史、分级着色的日志、菜单栏启停，全在原生应用里——不是 Electron 套壳。

诚实的 Provider 状态

available / ready / resident 三种状态严格分开，探测失败就如实说原因。是好事：状态含糊的系统，排障全靠猜。

快速开始

五分钟跑起来

需要一台 Apple Silicon Mac、macOS 14+、Rust stable 和 Xcode Command Line Tools；运行 Python 系列 Runner（MLX-LM、Kokoro、Qwen3-ASR/TTS、sherpa-onnx）需 Python 3.12。

1

构建 workspace

克隆仓库，在根目录把 daemon 和 CLI 编出来。

git clone https://github.com/GuanXuzeng/MacAI.git
cd MacAI
cargo build --release --workspace
2

启动 daemon 并注册模型

aiworkd 起来后监听 127.0.0.1:11435，随便找个本地 GGUF 注册进去就能聊。

./target/release/aiworkd
# 另开一个终端：
./target/release/macai load /path/to/model.gguf \
  --id local-model --type llm --keep-alive 5m --context-length 4096
./target/release/macai chat local-model "Hello" --temperature 0.2
3

接入 OpenAI SDK

任何 OpenAI 客户端，把 base_url 指过来就行，流式也一样。

# curl
curl http://127.0.0.1:11435/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"local-model","messages":[{"role":"user","content":"Hello"}]}'
4

打开原生控制台（可选）

通过 daemon 或 GUI「管理」页顶端一键安装 llama.cpp、whisper.cpp 和其他 Runner；原生引擎与 Python 环境共享同一管理面。

curl -X POST http://127.0.0.1:11435/api/runners/org.macai.llama.cpp/install

curl -X POST http://127.0.0.1:11435/api/runners/org.macai.whisper.cpp/install
./scripts/download-whisper-model.sh base

# GUI 控制台
cargo build --release -p ai-daemon
cd apps/MacAIConsole && scripts/build-app.sh release
open build/MacAIConsole.app
受管引擎生态： llama.cpp Runner（固定产物 + sha256） whisper.cpp Runner（官方 source + sha256） whisper 模型脚本下载 七个 Runner 的环境由 daemon 统一管理

OpenAI Python SDK 
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:11435/v1",
    api_key="local",
)

resp = client.chat.completions.create(
    model="local-model",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
