# 使用者与开发者统一文档体系（docs/guide/）

Status: implemented

## 问题

此前，MacAI 将用户日常使用与开发者底层实操分拆或割裂维护，导致用户与开发者在不同页面间来回跳转；同时，
缺少一个兼顾“普通用户快速上手”与“开发者深度工程实操”的统一分级文档目录。两份独立文档还存在架构阐述、
命令索引与目录结构等多处内容漂移风险。

## 决策

将使用者指南与开发者文档全面整合入单页静态站点 `docs/guide/index.html`，建立清晰的 6 大主题模块与 27 个分级锚点：

1. **六大模块分级目录设计**：
   - **快速入门**：系统定位与要求、安装与启动（DMG 绕过 Gatekeeper + 源码构建两手抓）、五分钟跑通主线；
   - **控制台与日常使用**：MacAIConsole 导览与无状态客户端设计、模型获取三种途径与注册语义、Chat / STT / TTS 核心能力实操；
   - **Runner 引擎实操**：Runner 独立子进程架构与统一环境管理，详尽展开全部 7 个生产 Runner 引擎（llama.cpp、whisper.cpp、
     Qwen3-ASR、sherpa-onnx、Kokoro、Qwen3-TTS、MLX-LM）的具体安装命令、权重文件规范、环境变量覆盖与自制 Script Runner 扩展；
   - **接口与客户端参考**：`macai` CLI 完整命令表、分层 HTTP API 矩阵、第三方应用（CherryStudio、Hermes）接入案例；
   - **核心架构与内部机制**：系统架构 ASCII 拓扑、Runtime Authority 调度与内存租约（Lease / Busy Guard / LRU）、受管数据目录树与环境变量、安全边界与数据最小化隐私守则；
   - **工程规范与故障排查**：多语言构建验证与测试流水线（Cargo / Swift XCTest / Runner pytest）、完整仓库结构地图、10 条按症状组织的折叠式故障排查卡片。
2. **零依赖与单页自包含体验**：
   - 沿用统一的深色 Apple 设计系统，纯原生 HTML + CSS + JS 实现，本地双击即可离线阅读；
   - 桌面端粘性侧边栏与移动端下拉目录双端支持，利用 `IntersectionObserver` 实时高亮当前阅读章节；
   - 所有代码块均挂载一键复制交互按钮。
3. **跳转兼容与互链收敛**：
   - 保留 `docs/developer.html` 与 `docs/developer/index.html` 作为无缝自动跳转页，重定向至 `guide/index.html`；
   - 主页 `docs/index.html` 导航与页脚链接收敛为「使用与开发文档」（`guide/`）；
   - 根 `README.md` 统一指向该综合文档。

## 备选

- **保持双独立站点（docs/guide/ 与 docs/developer/）**：用户与开发者边界在端侧 AI 运行时场景并不绝对割裂（例如高阶用户同样需要理解 GGUF 与 MLX 格式差异或排查环境安装），双页面维护成本翻倍，且缺乏统一上下文。放弃。

## 后果与边界

- 文档总览更加系统连贯，读者可通过左侧目录快速在“日常操作”与“底层机制”之间自如跳转；
- 行为以代码、测试与已落地决策为唯一事实依据，文档页脚声明最后更新日期与权威来源。

## 验证

- 自动化脚本校验：页面内侧边栏 27 个目录锚点与移动端 27 个锚点均 100% 对应真实 `<section>` ID，零死链；
- 静态资源离线校验：无任何外部 CDN 资源，全部使用相对路径；
- 语法与样式目验：响应式断点在桌面（≥960px）与移动端（<960px）均正常适配；
- 代码库规范检查：`cargo fmt --all -- --check` 退出码为 0。
