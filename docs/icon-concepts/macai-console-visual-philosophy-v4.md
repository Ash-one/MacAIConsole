# 白昼回路（Daylight Circuit）

高级感来自光线、比例与秩序，而非沉重材质。画面以珍珠白、柔雾灰和极浅冰蓝构成开放的明亮空间，像清晨光线落在精密玻璃与陶瓷表面。大面积底色保持安静、通透和完整，只有极细微的冷暖变化建立深度，使整个对象轻盈，却仍保有系统工具应有的可靠感。

Apple 标志成为本地平台核心，以平滑的深石墨色或半透明烟灰色呈现，与明亮背景形成克制而清晰的对比。标志保持完整、平面、没有金属拉丝或厚重浮雕。它不是装饰性的徽章，而是一枚嵌入核心表面的平台印记，安静地说明所有能力都从 Mac 本地出发。

电路承担智能编排的视觉语言。三条线路从核心分别出发，各自经过清晰、精确的圆角直角转折，再抵达三个彼此独立的节点。线路之间保持充分间距，节点之间不互相连接；转折建立工程秩序，分路建立多模型与多服务的含义。每一段水平线、垂直线与圆角半径都应像高端电路设计一样经过严密校准。

颜色只在信息发生的位置出现。电蓝与青蓝沿三条独立回路流动，在转角与端点处略微增强，却不形成霓虹泛光。节点是精确的小型端口，而不是立体按钮；线条具有足够视觉重量，在 Dock 小尺寸下仍能读出分支与转折。所有蓝色元素共同形成一套可追踪的运行路径。

最终图标应像一块由光、玻璃与电路组成的精密 macOS 控制器：明亮、克制、原生、安静。第二次审视不再添加装饰，只调整留白、线路转折、节点独立性和 Apple 标志的比例，使每个元素都拥有明确职责，并在长久使用中保持清晰与尊严。
